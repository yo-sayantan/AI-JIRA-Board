My Jira Board

A personal, beautiful replacement for staring at the Jira web UI. It renders tickets a background fetcher pulls for you — no Jira login, no waiting on the browser. This page gets you from clone to running board.

Before you start — what you need

Docker Desktop (the easy path), and one Jira Personal Access Token. That's the only token the board strictly needs. Confluence and Bitbucket tokens are optional and just add richer detail. Node.js is only needed if you want to build the app or run the local server instead of Docker.

Your tokens never enter this repo. They live in one file outside it (~/.cursor/mcp-secrets.env). Everything else points at it by path.

Setup — three files

1

Clone the repo

git clone <your-repo-url> jira-board
cd jira-board
2

Create your secrets file

Copy the template out of the repo and lock it down, then paste in your Jira token.

cp setup/mcp-secrets.env.template ~/.cursor/mcp-secrets.env
chmod 600 ~/.cursor/mcp-secrets.env
# then edit it and set:
#   JIRA_URL=https://jira.your-company.example
#   JIRA_PERSONAL_TOKEN=<your token>

Jira → your avatar → Profile → Personal Access Tokens → Create token. Read scope is enough. Copy it immediately — you can't see it again.

3

Fill in your config

Who you are and your company's URLs. No tokens here.

cp setup/config.example.json jira-intern/config.json
# edit jira-intern/config.json: your name (exactly as Jira shows it),
# your endpoints, and the footer branding

Every key is documented in jira-intern/CONFIG.md.

Deploy — one command (Docker)

4

Build, fetch, and serve

This builds the app, pulls your tickets on start, auto-refreshes every 15 minutes, and serves the board.

docker compose up -d --build

Then open http://localhost:4321/dist/index.html ✓ done.

macOS shortcut: copy setup/Start Jira Board.command.template to your Desktop, set the repo path inside it, chmod +x it, and double-click to build + deploy + open — no terminal needed.
Changed code in src/? Re-run with --build. Changing only data does not need a rebuild — the container refetches.

Everyday commands:

docker compose logs -f     # watch fetch + server logs
docker compose down        # stop

Other ways to run

📄 Static file

No server. If a dump exists, just open the single-file build:

open dist/index.html

Press r to re-read the latest data.

🖥️ Live server

The header button runs the fetch on your machine:

npm install
npm run serve

Opens on port 4321 with a working Refresh.
